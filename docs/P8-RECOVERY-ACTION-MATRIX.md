# P8 Recovery Action Matrix

This is presentation policy, not a recovery state machine. P4/P5 prepared workflow state and the existing product
error taxonomy remain authoritative. `Verified progress is safe` means only receiver-committed verified work in the
supported current recovery path; it never means a transfer is complete.

| Condition                                                                                | Product state / mode                                                            | Automatic recovery?              | Verified progress safe?                     | Terminal?                     | Primary action                                                     | Secondary action                                                      | New transfer required?                                                           |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------- | ----------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------- | -------------------------------------------------------------------------------- |

| Route recovery while the existing route mechanism continues                              | `RECONNECTING` / automatic                                                      | Yes                              | Yes, if the prepared state is authoritative | No                            | None                                                               | Cancel through the existing workflow                                  | No                                                                               |

P8 does not expose manual route selection, verified-block reset, resume metadata editing, candidate data,
credentials, or protocol controls. Manual reconnect control is not implemented; the qualified current recovery API
owns automatic reconnecting.
