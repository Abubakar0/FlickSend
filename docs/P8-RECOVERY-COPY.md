# P8 Recovery Copy

This catalog records the canonical user-facing strings already rendered by P4, P5, and P7. Product error codes and
technical details are never ordinary user copy. Names in brackets are prepared display names, not raw identifiers.

| Situation                        | Rendered heading / status                                                                          | Canonical explanation or supporting text                                                                        | Action                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Automatic reconnect              | Reconnecting                                                                                       | Connection interrupted. Your verified progress is safe.                                                         | Keep FlickSend open while it reconnects.                              |
| Still reconnecting               | Reconnecting                                                                                       | No separate `Still reconnecting` string exists; the active automatic-reconnect copy remains in place.           | Keep FlickSend open while it reconnects.                              |
| Restored connection              | Connection restored                                                                                | Continuing from verified progress.                                                                              | Keep FlickSend open while the transfer continues.                     |
| Waiting for recipient            | Waiting for [recipient]                                                                            | Keep FlickSend open. The transfer will start when [recipient] is ready.                                         | None.                                                                 |
| Waiting for sender               | Waiting for [sender], or Waiting for sender before authorized metadata exists                      | Keep FlickSend open while the sender becomes available. A prepared destination adds: Your destination is ready. | None.                                                                 |
| Route recovery exhausted         | Couldn't reconnect                                                                                 | FlickSend could not restore this transfer connection. Nothing unverified was marked complete.                   | Start a new send, or ask the sender to start a new transfer.          |
| Source changed                   | Source changed                                                                                     | The file or folder changed while it was being sent, so this transfer stopped to keep the result correct.        | Choose source again, or ask the sender to start a new transfer.       |
| Destination changed              | Destination changed                                                                                | Previously saved verified data no longer matches what FlickSend expected.                                       | Ask the sender to start a new transfer.                               |
| Destination permission lost      | Can't save there                                                                                   | FlickSend no longer has permission to write to this destination.                                                | Choose another destination.                                           |
| Destination unavailable          | Destination unavailable                                                                            | FlickSend can no longer safely write to the selected destination.                                               | Choose another supported destination.                                 |
| Not enough storage               | Not enough space                                                                                   | The destination could not continue saving this transfer.                                                        | Free space or choose another destination and receive again.           |
| Integrity retry                  | Checking transferred data                                                                          | FlickSend is checking what can continue safely.                                                                 | Keep FlickSend open while checking continues.                         |
| Integrity exhausted              | Transfer couldn't be verified                                                                      | FlickSend could not verify this transfer. Nothing has been marked complete.                                     | Start a new transfer after checking the source and destination.       |
| Destination finalization failure | Couldn't finish saving                                                                             | FlickSend could not finish the destination, so nothing was marked complete.                                     | Check the destination and receive again.                              |
| Service unavailable              | FlickSend is temporarily unavailable                                                               | A service needed to arrange the transfer is unavailable.                                                        | Try again shortly.                                                    |
| Browser capability unavailable   | Sender: This browser can't complete that action. Recipient: This browser can't save this transfer. | A required browser capability is unavailable or not qualified for this action.                                  | Use a qualified Windows desktop browser or choose a supported action. |
| Explicit cancellation            | Transfer canceled                                                                                  | Nothing has been marked complete. Existing partial destination data was not automatically deleted.              | Start a new send when ready.                                          |
| Unknown transfer failure         | Transfer couldn't continue                                                                         | FlickSend stopped this transfer to avoid an incorrect result.                                                   | Try again; if the problem continues, start a new transfer.            |
| P7 recovery detail               | Recovered through [count] reconnection(s).                                                         | Observed recovery summary only; it is not a network diagnostic console.                                         | None.                                                                 |

Use the word `safe` only in the two supported current-recovery strings above. Do not append a safety claim to source
or destination mutation, permission/storage errors, explicit cancellation, refresh/restart, background/sleep,
offline periods, or unknown/unqualified interruptions. Do not include raw codes, session/transfer IDs, paths,
filenames, network identifiers, credentials, stack traces, or raw diagnostics in ordinary copy.
